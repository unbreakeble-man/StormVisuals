# StormVisuals · Click GUI

## HUD · Ватермарка

В `hud.html` добавлен макет Potions слева: три примера эффектов с оригинальными Minecraft-иконками, русским названием, уровнем и таймером. Скоро заканчивающийся эффект выделен тёплым оттенком таймера. Размер блока — 210 px; таймеры находятся в небольших плашках; фон и блюр как у ватермарки, русские названия — Montserrat Regular, таймеры — Montserrat SemiBold. Значения демонстрационные.

Открой `hud.html` или `http://127.0.0.1:8765/hud.html` при работающем локальном сервере.
Ватермарка закреплена по центру сверху; верхние углы прямые, нижние — 13 px.
Круглый логотип, Storm, FPS, ms и TPS с отдельными SVG-иконками. Значения — примеры для макета.
Подложка использует цвет Minecraft Click GUI `#080808`; в HTML-макете непрозрачность уменьшена до 62%, блюр — 28 px с нейтральными цветами, тень стала заметнее. Для HUD используется чёткий игровой скриншот `assets/hud-world.png`.
Comfortaa для английского текста, Montserrat SemiBold для чисел. Все ресурсы локальные; лицензия Montserrat в `assets/MONTSERRAT_OFL.txt`.

## Click GUI

Открой `index.html` в браузере. Установка и сборка не нужны, все ресурсы локальные.

- ЛКМ по карточке или переключателю — включение/выключение.
- ПКМ по шапке карточки — раскрыть настройки внутри неё. С клавиатуры: Shift+F10.
- Поиск фильтрует модули. Esc / крестик закрывает окно; кнопка StormVisuals открывает его снова.
- Это интерактивный дизайн: настройки меняют состояние элементов макета, к Minecraft он пока не подключён.

Основа — Figma-файл Ltzenf9MLM3NumMJduupd2, Minimal Click GUI и состояние ПКМ. Окно сужено до 880×560, добавлены группы сайдбара. Comfortaa Regular, карточки 70 px, радиусы 32/12/8 px, чёрный фон 75%, backdrop blur 50 px. Фон взят из экспортного превью исходного наброска (210×119), поэтому вне окна он менее чёткий, чем оригинал Figma. Для чёткого фона можно заменить `assets/world.png` исходным скриншотом.

Шрифт распространяется по SIL Open Font License; лицензия в assets/COMFORTAA_OFL.txt.
