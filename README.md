# StormVisuals

Клиентский визуальный мод для Minecraft 1.21.11 / Fabric с редактором HUD-элементов поверх обычного игрового чата.

HUD-слои регистрируются через `HudRenderSystem.addLayer(...)` до вызова `HudRenderSystem.initialize()` в клиентском entrypoint. Слой получает штатные `GuiGraphics` и `DeltaTracker` для Minecraft 1.21.11. Система сама размещает слой перед чатом и не вызывает его вне игрового мира.

`RoundedRectRenderer.draw(graphics, rect)` рисует прямоугольник через GLSL с независимым радиусом четырёх углов и цветом ARGB. Параметры можно менять каждый кадр без пересоздания шейдера. Радиусы автоматически ограничиваются половиной меньшей стороны.

Откройте мир и нажмите `T`, чтобы открыть обычный чат и редактор. ПКМ по пустому месту холста открывает меню создания прямоугольника, квадрата, скруглённого прямоугольника, круга, текста или PNG. ЛКМ по элементу выделяет и перемещает его; восемь маркеров меняют размер. Справа находятся свойства и действия: копия, удаление, перемещение вперёд или назад. `Ctrl+Z` и `Ctrl+Y` отменяют и возвращают изменения, `Ctrl+D` создаёт копию, `Delete` удаляет выделенный элемент. Клик по пустому месту снимает выделение. Чат продолжает работать как обычно.

Текст создаётся через `ПКМ → Текст`: введите строку, затем `Enter` для сохранения или `Esc` для отмены. Выделенный текст можно снова открыть кнопкой «Изменить текст», поменять размер и каналы ARGB. Весь текст рисуется MTSDF-шейдером со шрифтом Comfortaa Regular; отсутствующие символы заменяются на `?`.

PNG можно сначала скачать или сохранить в любое место на компьютере, затем в игре открыть чат клавишей `T`, нажать ПКМ по пустому месту холста и выбрать `PNG файл...`. Откроется системный выбор файла; клиент сам скопирует PNG в `config/stormvisuals/images/` и загрузит текстуру без перезапуска. Выделенную картинку можно заменить кнопкой «Заменить PNG». Максимум: 16 МБ и 4096×4096 пикселей.

Макет сохраняется автоматически в `config/stormvisuals/layout.json` и загружается при следующем запуске. Предыдущий формат макета с одними фигурами также читается. Элементы видны в игровом HUD и при закрытом чате.

Исходный TTF, набор символов, метаданные атласа и лицензия OFL лежат в `src/main/resources/stormvisuals/font/`; PNG-атлас — в `src/main/resources/assets/stormvisuals/textures/font/`. Атлас создан официальным `msdf-atlas-gen` 1.4 с параметрами `-type mtsdf -size 48 -pxrange 8 -potr -yorigin top`.

Нужен JDK 21. Сборка: `./gradlew.bat build`. Запуск клиента для разработки: `./gradlew.bat runClient`. Готовый мод: `build/libs/stormvisuals-0.1.0.jar`; для обычного запуска нужны Fabric Loader и Fabric API той же версии Minecraft.
